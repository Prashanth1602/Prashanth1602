## ⭐ Featured Projects

### 🎬 [Movie-Review-API](https://github.com/Prashanth1602/Movie-Review-API)

> A production-grade, API-first backend built with FastAPI for managing movies and user reviews

**Key Highlights:**
- 🔐 **Secure JWT Authentication** – Dual-token system (access & refresh tokens) with token rotation
- 🔑 **OAuth Integration** – Google OAuth login via ID token verification
- 🛡️ **RBAC** – Role-based access control with granular permissions
- 🚦 **Advanced Rate Limiting** – API key–based external access with token bucket rate limiting
- 🔍 **Vector-Based Search** – Semantic movie search capabilities
- 🐳 **Cloud Deployment** – Fully containerized with Docker, deployed on AWS EC2
- 🏗️ **Production Architecture** – Stateless authentication, service isolation, and scalable design

**Tech Stack:** FastAPI, PostgreSQL, Docker, AWS EC2, JWT, OAuth2

---

### 📝 [Smriti – Notes App Backend](https://github.com/Prashanth1602/notesApp-backend)

> A modular, production-oriented FastAPI backend providing secure, user-scoped note management

**Key Features:**
- 📄 **CRUD Operations** – RESTful API for seamless notes management
- 🔐 **JWT Authentication** – Secure auth with refresh token rotation
- 🔒 **Data Isolation** – User-level authorization & data scoping
- 🔍 **Full-Text Search** – PostgreSQL FTS with prefix matching for efficient searching
- 📊 **Database Migrations** – Alembic-managed schema versioning
- 📋 **Structured Logging** – Rotating file handlers for observability

**Tech Stack:** FastAPI, PostgreSQL, Alembic, JWT
